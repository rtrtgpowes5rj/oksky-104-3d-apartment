# Окский 104 — интерьер v6

[Открыть интерактивную 3D-прогулку](https://rtrtgpowes5rj.github.io/oksky-104-3d-apartment/)

Откройте `dist/index.html` в современном браузере с WebGL2. Все материалы и код встроены в этот файл; интернет для просмотра не нужен. Исходники: `npm install`, `npm run dev`. Проверки: `npm run validate`, `node scripts/test-controls.mjs`, `npm run build`.

## Что изменено

- Новая светлая сцена с физическими материалами, контактными тенями, дубом, текстилем и детальной мебелью.
- Глубокий тёмно-синий объёмный диван с отдельной navy-вельветовой фактурой, мягко скруглёнными секциями и охристо-терракотовыми подушками; серое кресло-мешок в кабинете.
- Банкетка стоит справа от входа и не пересекается с дверью; собачья лежанка перенесена к дивану.
- Кошачий лоток находится в углу санузла №1, а стиральная машина открывается в сторону входа.
- Компьютерные кресла развёрнуты к мониторам; лаунж-кресло — к растению. Случайное растение из середины прохода убрано.
- Исправлены локальные оси мебели: стиральная машина и оба унитаза стоят задней частью к стенам. Ванна имеет внутреннюю чашу.
- Такса в гостиной, лежанка в прихожей, кошка на комплексе с когтеточкой в детской, три миски на коврике на кухне.
- Кабинет отделён глухой стеной с непрозрачной дверью.
- Макет, вид сверху, прогулка, карта помещений, дневной/вечерний свет, две палитры, сохранение кадра.
- Геометрия объединена по материалам, тени обновляются при изменениях, разрешение ограничено, частота отрисовки ограничена примерно 60 FPS, скрытая вкладка не рисуется.

## Управление

Макет: левая кнопка — вращение, правая — сдвиг, колесо — масштаб. Прогулка: WASD/стрелки — движение относительно взгляда, перетаскивание мышью — осмотр, колесо — изменение угла обзора. Двойной щелчок включает захват мыши, Escape освобождает. На сенсорном экране доступны кнопки движения. Комнаты в меню — быстрые точки перехода.

## Границы точности

Это интерьерный 3D-концепт, не обмерный или строительный проект. Расположение зон восстановлено по перспективному изображению перепланировки без размерных цепочек. На референсе указано 62,49 м², но сумма подписанных площадей помещений составляет 64,01 м². Подписи сохранены как данные референса; их нельзя считать результатом точного расчёта модели. Для рабочей документации нужны обмеры, высоты, стояки и подтверждённые размеры проёмов.

2,5 млн ₽ — исходный бюджетный ориентир пользователя, не подтверждённая смета и не предложение поставщиков. Концепция предполагает серийную мебель, окрашенные стены, ограниченную акцентную отделку; закупки и ремонт по этим визуализациям без отдельной сметы не планировать.

## Материалы

Poly Haven: https://polyhaven.com/a/wood_floor, https://polyhaven.com/a/rough_linen, https://polyhaven.com/a/white_plaster_02. Оригинальные изображения в `public/assets`.

Текстуры созданы встроенным ImageGen (builtin mode), не внешним API: `art.png` — абстрактная картина; `corduroy-navy.png` — актуальный материал дивана. Промпты сохранены в `asset-prompts.md`. Геометрия мебели и питомцев реальная трёхмерная, стилизованная, не фотографическая.
